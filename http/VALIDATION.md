# 本机 HTTP 验证范围

以下为维护者在Windows与Chrome本机环境中的验证摘要，截至2026-11-05。历史结果按代码变更影响沿用或补测，各项结果限于对应样本和客户端。

| 范围 | 已验证内容 |
|---|---|
| stdio与HTTP协议 | 官方SDK独立连接、10工具、3模板、初始化指引、图片与错误原样转发 |
| 会话与异常 | 来源隔离、过期、重复在途请求、断线不重放、超时后停止派发、子进程退出及关闭清理 |
| 本机访问保护 | Bearer认证、Host/Origin校验、端口冲突及令牌隐私排除 |
| Codex stdio | 实际工具调用完成状态、搜索、正常卡片进入、主图及完整默认规格参考价读取 |
| HTTP页面读取 | 独立会话完成搜索、详情、主图及完整规格参考价读取，90秒串行间隔下长请求正常结束 |
| SKU数量诊断 | stdio与HTTP分别核对混型号商品的默认规格、页面数量和目标选项禁用原因 |
| 独立安装 | 干净源码目录安装、9适配器发现、stdio冒烟、HTTP启动、10工具、3模板及写权限关闭 |
| 核心保护 | 固定基线、经审阅的逐文件哈希变更、依赖及安装约束检查 |

SDK与异常分支通过隔离环境验证；真实页面读取使用各自的正常搜索来源。测试方法和复现命令见[TESTING.md](../TESTING.md)。

## 兼容范围与限制

- HTTP转接已有读取器，不扩大页面兼容范围。缺少安全规格入口的页面无法完成相应组合核验；另有页面出现`bound_sku_state_mismatch`，该页面的规格关联仍待诊断，不能用于确认参考价。
- 默认组合核价和非默认组合切换分别记录；数量诊断不计作新的非默认切换成功。
- 参考价保留拼单、补贴、优惠资格及运费未知项，不代表最终成交价。明确多人团商品不纳入默认推荐。
- Codex已有实际调用与重启恢复记录。豆包、WorkBuddy及其他物理电脑尚未实测；SDK连接成功不能代替具体客户端验证。
- 其他使用者须在自己的电脑安装，绑定自己的浏览器与登录会话，并确认客户端支持本机URL、Bearer认证和足够长的调用超时。

## 依赖与记录

2026-11-04的依赖审计中，HTTP依赖无告警，主项目固定依赖有1项moderate及1项high告警；这不代表持续审计结果。依赖升级需单独评估，SDK的MIT许可正文保留在`third-party/`。

原始调用、运行文件哈希和脱敏页面证据保存在维护者本机，公开源码保留必要回归测试和fixture。页面核对、用户确认及预览包发布分别记录，不由SDK或自动测试代替。
