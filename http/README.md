# 可选本机 HTTP 接入

原 Codex stdio 入口继续使用。此模块通过官方 MCP SDK 1.32.2，将每个 HTTP 会话转接到同目录原 `server.cjs`，共用浏览器锁、90秒间隔和原读取逻辑。10工具、3模板及参数保持兼容，HTTP 子进程强制关闭写权限。

## 安装和启动

先按主项目说明安装、绑定本机浏览器并人工登录，再在同一源码目录执行：

```powershell
npm run check:frozen
npm run setup:http
npm run start:http
```

默认地址是 `http://127.0.0.1:4176/mcp`，仅监听本机。保持启动终端运行；停止 HTTP 不需要停止 Chrome，也不需要修改 Codex 配置。

安装器生成 `outputs/mcp-http.connection.local.json`，其中包含 URL、Authorization 请求头和建议超时。按客户端的设置界面分别填写；该文件是连接资料，不宣称能直接导入所有客户端。不要把含令牌的文件或截图发到聊天、Issue或仓库。

- 传输：MCP Streamable HTTP，支持 POST、GET、DELETE。
- 认证：Authorization 请求头，值为本机连接文件中的 Bearer 令牌；不接受 URL 查询参数传令牌。
- 工具调用超时：建议至少300秒，按步骤串行调用。流式协议不表示可以忽略客户端超时。
- CDP端口是浏览器连接配置；9335或9222不能填写成 MCP 服务端口。

需要其他 HTTP 端口时，停止旧 HTTP 进程后，在同一终端运行：

```powershell
$env:PDD_HTTP_PORT = '4177'
npm run setup:http
npm run start:http
```

端口占用会报错，不自动换端口。重新 setup 保留已有令牌。配置损坏时明确报错，不自动清除或覆盖令牌。HTTP 配置不改动原浏览器绑定、stdio配置或全局客户端设置。

## 会话和异常

一次搜索及后续详情、规格请求须保持同一 MCP 会话。新的会话重新搜索，不能借用另一连接的候选。来源仍按原服务30分钟期限处理；HTTP重连不延长来源有效期。

最多保留4个 HTTP 会话，空闲30分钟后释放；执行中的原调用等待结束后才清理子进程。普通 HTTP 请求断开不杀死原调用，也不重放。超时或底层执行无法确认时，该会话停止派发新的页面请求，可检查状态；确认现场后关闭旧会话，再显式搜索。

HTTP与stdio可同时连接，但同一浏览器的选品任务依次执行；不要让两个客户端同时操作页面，也不要从两个不同安装目录共用一个浏览器。正常使用不需要运行维护者验收控制器。

## 客户端兼容

客户端需能从本机访问 URL、发送 Bearer 请求头、保持 MCP 会话，并支持足够的调用超时。HTTP SDK协议验证与具体客户端验收分别记录。

豆包若要求云端HTTPS、OAuth、旧式SSE或无法携带认证请求头，本模块不能据此标为兼容；本轮不提供公网隧道或远程部署。其他电脑需自行安装、绑定并登录自己的浏览器，不连接维护者电脑。
